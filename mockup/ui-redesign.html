交互逻辑升级

  • 顶栏常驻入口：设置、日志提到 App Bar，不必滚 2 屏。
  • 连接分阶段反馈：连接中展示「网卡 → 引导节点 → 隧道 → 就绪」四步，失败能定位卡在哪。
  • 失败给原因和动作：超时不再只显示 "Timeout"，而是「引导节点无响应，检查网络后重试」+ 重试按钮。
  • 长按代替点击：Peer ID / IP 长按弹出菜单（复制 / 二维码 / 详情），避免现在「一点就复制」的误触。
  • 状态副标题承载信息：已连接时直接显示「直连 3 · 中继 1 · RTT 42ms」，替代原来空泛的提示语。

顺手修掉的缺陷

  • 底部按钮文字被裁切：GitHub / Developer 按钮 44dp 高放 12sp 两行文字，"Repository" 和 "@NNdroid" 被切掉。改单行 + 省略或加高。
  • 主标题硬编码英文：activity_main.xml 里 app:title="P2PTap Virtual Network" 不走 i18n，10 个 locale 全部失效。
  • System Health 与 Protocol 抢主屏：4 个开发者指标区块占掉一屏，普通用户用不到。
  • IPv6 行恒为 visible：layoutTapIpv6 在 Kotlin 里被强制设 VISIBLE，即使没有 v6 地址也占一行。
  • Web Console 按钮只在 RUNNING 可用，但位置在最底部，用户连接成功后还得往下滚才能点。

落地范围

  • 保留 View + XML，不迁 Compose：现有 10 locale + values-land / w600dp / w1240dp 三套平板布局要全部重写，且 Go JNI 已每 ABI 34MB。
  • 新增 layout/content_main.xml 重构版 + item_advanced_*.xml 子布局。
  • 新增 strings.xml 键 ~14 个，同步 10 个 values-*（先出英文+简中，其余留待翻译）。
  • MainActivity.kt 改造：状态机文案、折叠区展开动画、长按菜单、i18n 标题。
  • 新增 dimens.xml token 与 ic_chevron 等 3 个矢量图。

说明：本 mockup 只是视觉与交互提案，未改动任何工程代码。左侧「改造前」按现有 content_main.xml + 截图复刻， 用于对照信息密度差异；右侧两屏为重构后的目标形态。深色科技感保留，但我把原来的「大色块渐变」收成了「状态色驱动的局部光晕」—— 连接是绿色光晕、连接中是琥珀、错误是红色，颜色本身就在传递状态。
